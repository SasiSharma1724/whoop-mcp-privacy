# Privacy Policy for Sashi WHOOP MCP

Last updated: October 12, 2026

Sashi WHOOP MCP is a personal development project maintained by Sashi. It is intended to let its owner access their WHOOP recovery data through a locally operated Model Context Protocol (MCP) server. It is not currently offered as a public service.

## Information accessed

When you authorize the application through WHOOP, it can access recovery information permitted by the `read:recovery` permission, including recovery scores, heart rate variability, resting heart rate, and related recovery measurements and timestamps.

The application uses OAuth credentials and tokens to access authorized data. Your WHOOP password is entered on WHOOP’s authentication page, not collected by this application.

## How information is used

Recovery data is used to answer requests made through the MCP tools and to test the personal integration. It is not sold or used for advertising.

## Storage and retention

The application runs locally. Authorization tokens may be stored on the computer running it until deleted or replaced. Recovery responses may remain in terminal output, saved exports, or the history of a connected client until those copies are deleted.

Credentials, tokens, and recovery data are not intended to be published in the public GitHub repository.

## Connected applications

The MCP server returns requested data to the client connected to it. If you connect an AI application or cloud service, that service may receive and retain the returned data under its own privacy policy and settings. Running the MCP server locally does not guarantee that data stays on your computer after it is sent to a connected service.

## Revoking access and deleting data

You may revoke the application’s authorization through WHOOP’s connected-application controls. Revoking access does not automatically delete copies already stored locally or by connected clients.

To remove those copies, delete locally stored tokens, exports, and logs, and use the deletion controls of any connected services.
